## 设置容器 Bug 修复（v5.3.4 → v5.3.5，已提交 db12eae）

- **Bug1 动画失效**：`SheetContent` 的 `@keyframes slideIn` 写在 `<style jsx>`（scoped，带 hash 前缀），`animation:"slideIn"` 引用全局名不匹配 → 滑入动画不播、开关闪烁。修复：改 `<style jsx global>` 并重命名为 `sheet-slideIn`，同步 `style.animation` 引用。

- **修复1 面板结构**：移除 SettingsPanel 内多余嵌套 `Sheet`（此前 `open={!autoHide}` 在默认 autoHide=true 时令面板内容打不开），改纯内容容器，由外层 app-header 的 Sheet 统一控制显隐。
- **修复2 自定义名单开关缺失**：此前用户无法主动启用/停用自定义列表（useCustomList 由 persistence 驱动但 UI 未暴露）。现 DrawSettings 抽取设置区新增「使用自定义名单」Switch，并把 useCustomList/setUseCustomList 从 draw 解构经 settings-panel 透传；CustomListInline 在名单已填但未启用时给 amber 提示（listNotEnabledHint）。
- **修复3 重复项阻断保存**：custom-list-settings 此前有重复项直接 `setError` 并 return 拒绝保存（与「保存时自动去除」文案矛盾）。改为自动去重后保存，并提示去除数量（duplicateItemsWarning 加 `{0}` 占位）。
- **修复4 allowDup 文案错用**：draw-settings 允许重复卡片下方误用 `customListHint`，改为新增 `allowDupDesc`。
- **修复5 预览误导**：appearance-settings 数字格式预览在自定义名单模式下显示「格式不生效」（listModeFormatNote/notApplicable），不再套用 digits 补零。
- **修复6 滑块上限过窄**：count max 20→100、duration max 10→30（逻辑硬上限 1000/120 仍作防护，UI≤逻辑即可）。
- **i18n**：新增 `allowDupDesc`/`listModeFormatNote`/`notApplicable`/`listNotEnabledHint`，duplicateItemsWarning 加 `{0}` 占位；types.ts TranslationKey 补全；zh/en 同步。
- **验证**：`tsc --noEmit` 通过，lint 0 错误。版本全同步至 **v5.5.0**（minor：设置功能修复完善），CHANGELOG 新增 [5.5.0] 小节。
- **项目事实更新（可复用）**：Zen-Draw 当前实际翻译键约 116（zh/en/types 强约束对齐）；主题 11 套 `.theme-<preset>` 类驱动（default/ocean/forest/sunset/purple/neon/sakura/midnight/retro/pixel/rose），深浅靠 `.dark` 类，与原型 design-system.md/tokens.css 的 `[data-theme]` + Graphite/Mono 命名完全不符（原型已过时，见本轮原型审查）。
