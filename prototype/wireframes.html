设置容器 Settings Container（右侧抽屉 + Tabs）

应用全局设置入口为右侧滑入抽屉，由顶部导航的齿轮按钮触发。结构固定为： HeaderBar（应用标识 + 版本号 + 语言切换） → Tabs（抽取 / 外观 / 体验 / 历史）。 下方按钮可预览真实抽屉（含 Tab 切换、Esc 关闭、遮罩点击关闭）。

触发与结构

• 位置：右侧（side="right"）
• 宽度：移动端全宽；≥640px 为 26rem
• 动效：300ms 滑入（--dur-slow）
• 关闭：Esc / 遮罩点击 / 无独立关闭按钮（HeaderBar 语言键在右）
• 语义：role="dialog" aria-modal="true" + 遮罩 aria-hidden

Tabs 分区
  • 抽取 · min/max/count/duration/允许重复/自定义名单
  • 外观 · 主题预设/字体/语言/数字格式/预览
  • 体验 · 音效/彩屑/减弱动效/自动收起/密度/重置
  • 历史 · 列表 + 清空
