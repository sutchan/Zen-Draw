组件使用规则

8 条核心规范，覆盖圆角层级、栅格、触控、间距与状态。

✓ Do

圆角分层：卡片/面板用 --radius-lg/xl，按钮/标签用 --radius-full，输入框用 --radius-md。

✗ Don't

混用随机 px 圆角，如卡片用 10px、按钮用 4px，破坏统一感。

✓ Do

间距严格走 4px 栅格（--space-2/3/4/6…），组件内边距 ≥ --space-4。

✗ Don't

使用 5px / 7px 等非栅格间距，导致基线错位。

✓ Do

所有可点击元素最小触控目标 ≥ 44×44px（图标按钮至少 40px 且留白）。

✗ Don't

将图标按钮缩到 24px 且无内边距，移动端难以点击。

✓ Do

状态反馈闭环：Hover 上浮、Focus 焦点环、Active scale .97、Disabled opacity .4。

✗ Don't

仅做 hover 变色，忽略焦点可见性（键盘用户无法定位）。

✓ Do

表单错误态：红框 + 图标 + 文案三件套，文案指出如何修正。

✗ Don't

仅用红色文字提示，无边框/图标，弱视用户难以察觉。

✓ Do

语义色来自令牌（--success/--danger/--warning），不硬编码 hex。

✗ Don't

在组件内写死 #22c55e 等具体色值，破坏主题一致性。

✓ Do

业务组件组合基础/复合组件，不重复造底层样式。

✗ Don't

在 DrawDisplay 内重新定义按钮样式而非复用 .btn。

✓ Do

动效时长取自 --dur-200/300，长动效 ≤ --dur-700，并尊重 prefers-reduced-motion。

✗ Don't

使用 1200ms 以上无意义的位移动画，拖慢感知。
